# 技術資料

## ゲームの進行

`Game.phase`を使い、次の状態を順に遷移する。

```text
自軍ユニット選択
    ↓
移動先選択
    ↓
攻撃または待機
    ↓
攻撃対象選択
    ↓
行動終了・ターン交代
```

移動後に攻撃可能な相手がいない場合、攻撃は選択できず待機が初期選択になる。
Bボタンでは現在の状態を1段階戻し、確定前の移動も取り消せる。

## ユニットの移動・攻撃範囲

次の図はPlayer 1から見た範囲。Player 2では上下を反転する。
`○`が選択可能なマス、中央の文字が現在位置。

```text
Aの移動       Aの攻撃
・○・         ・○・  2マス前
○A○         ・○・  1マス前
・○・         ・A・

Bの移動       Bの攻撃
○○○         ○○○  2マス前
・B・         ・・・
○・○         ・B・

Cの移動       Cの攻撃
○○○         ○・○
○C○         ・C・
・○・         ○・○
```

Aの2マス攻撃は、通常時には間のユニットまたは通行不可地形で遮られる。覚醒後は間のユニットを貫通するが、通行不可地形には遮られる。
Bの攻撃と、B・Cの斜め移動およびCの斜め攻撃は途中のマスを判定しない。
どの移動でも、着地点が盤面内かつ空いており、通行可能である必要がある。

## ソース構成

| ファイル | 責務 |
|---|---|
| `source/main.c` | 初期化とメインループ |
| `source/game_types.h` | 定数、列挙型、ゲーム状態 |
| `source/game.c` | 選択、移動、攻撃、ターン交代、勝敗 |
| `source/board.c` | 移動可能判定、攻撃範囲、地形判定 |
| `source/unit.c` | ユニットの初期値と表示情報 |
| `source/input.c` | DSキー入力からゲーム入力への変換 |
| `source/render.c` | 上画面の盤面・スプライトと下画面UI |
| `source/japanese_text.c` | UTF-8の解析と8×8ドット文字描画 |
| `source/sound.c` | BGMと効果音の初期化・再生 |

ゲームルールはDSの描画APIから分離しており、`test/test_rules.c`をホストPCで実行できる。

## DS画面の構成

上画面では、16bitビットマップ背景として盤面を描き、その上にOAMスプライトでユニット、カーソル、移動範囲、攻撃範囲を重ねる。
下画面では、16bitビットマップへボタン、情報パネル、攻撃範囲図、日本語文字を直接描画する。

日本語はUTF-8をコードポイントへ変換し、収録した美咲フォントのグリフを描画する。
未収録文字は`?`として表示される。ライセンスは`docs/misaki-font-license.md`を参照。

## 地形

`TERRAIN_PLAIN`、`TERRAIN_MOUNTAIN`、`TERRAIN_RIVER`、`TERRAIN_BUILDING`を定義している。
山と湖（内部名`TERRAIN_RIVER`）は通行不可、草地と建造物は通行可能。
建造物上の自軍ユニットは、自分のターン開始時にHPを20回復する。
地形判定は`board.c`、ターン開始効果は`game.c`、表示は`render.c`へ分離している。

## 覚醒

各プレイヤーが最初に味方を失った後、次の自分ターン開始時に一度だけ覚醒選択を行う。
生存者が2体なら1体を選び、生存者が1体なら自動的に覚醒する。選択は行動回数を消費しない。

- A：通常40、覚醒70。覚醒後は前方1〜2マスの敵全員を攻撃
- B：通常30、覚醒40。覚醒後は2マス前の横3マスにいる敵全員を攻撃
- C：通常30、覚醒40。覚醒後は単体攻撃の命中時に自身のHPを20回復

覚醒状態と覚醒選択済み状態は`Game`に保持し、STARTによる再戦時に初期化する。

## 確認項目

- Player 1の全員が行動するとPlayer 2へ交代する
- 行動済みまたは戦闘不能のユニットを選択できない
- A・B・Cの移動と攻撃範囲が仕様どおりになる
- 移動候補ごとの攻撃可能範囲が表示される
- 攻撃でHPが減り、0になったユニットが盤面から消える
- 攻撃対象がいない場合は待機だけを選択できる
- Bボタンで選択と仮移動を取り消せる
- 全滅時に結果画面が表示され、STARTで再戦できる
- 覚醒の選択、自動覚醒、範囲攻撃、回復が仕様どおりになる
- 地形が180度回転対称を基準に配置され、建造物上のユニットだけがターン開始時に回復する
- BGM、選択音、勝敗決定音が再生される
