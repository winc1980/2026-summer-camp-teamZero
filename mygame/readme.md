# ゲーム本体

ビルド、操作、ゲームルール、テスト方法はリポジトリ直下の[README](../README.md)を参照。

## ビルド

Dev Container内で次を実行する。

```bash
cd /work/mygame
make clean
make
```

成功すると、このディレクトリに`mygame.nds`が生成される。
